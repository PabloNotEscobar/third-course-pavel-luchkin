# Занятие 1. Растровая графика, пиксели и алгоритм ЦДА

## Ответы

**Что такое растеризация?**
Растеризация — это процесс преобразования непрерывного геометрического объекта
(например, отрезка) в набор дискретных пикселей растра, которые лучше всего
его приближают.

**Зачем в ЦДА выбирается `max(|dx|, |dy|)`?**
Это число шагов, за которое нужно пройти от одной точки до другой так, чтобы
на каждом шаге координата, которая меняется быстрее (большая по модулю
разность), сдвигалась ровно на 1 пиксель. Если взять меньшее значение, между
соседними пикселями по этой оси будут пропуски (разрывы линии).

**Почему координаты приходится округлять?**
Потому что `x` и `y` в процессе накопления приращений (`xStep`, `yStep`)
становятся вещественными числами, а реальный пиксель на экране может иметь
только целые координаты. Округление выбирает ближайший к вычисленной точке
пиксель.

**Что произойдёт, если начало и конец отрезка совпадают?**
`dx = 0`, `dy = 0`, значит `steps = 0`. В этом случае цикл с делением на
`steps` не выполняется — вместо него просто закрашивается один пиксель в
точке `(x1, y1)` (обработано отдельной веткой в коде).

**Какие недостатки ЦДА вы заметили?**
- используются вещественные числа и деление на каждом шаге;
- накапливается погрешность округления на длинных отрезках;
- на каждом шаге нужно выполнять `Math.round`, что медленнее целочисленной
  арифметики;
- при вертикальных/горизонтальных линиях один из шагов равен 0, что работает
  корректно, но требует отдельной проверки `steps === 0` для случая точки.
