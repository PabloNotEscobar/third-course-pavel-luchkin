ПРАКТИЧЕСКАЯ РАБОТА №5. ЗАПОЛНЕНИЕ ОБЛАСТЕЙ: FLOOD FILL И SCANLINE

Два способа заливки одного и того же многоугольника на логическом растре 40 x 30:

- Flood Fill: заливка от стартовой клетки по соседним клеткам до границы;
- Scanline Fill: заливка по горизонтальным строкам через пересечения строки с рёбрами многоугольника.

Готовые заливки Canvas (fill(), ctx.fill()) не используются. Canvas только отображает массив grid.


КАК ЗАПУСТИТЬ

Установка и сборка не нужны. Откройте файл index.html в браузере (двойной клик). Работа написана на чистых HTML, CSS и JavaScript, дополнительных программ не требуется.

Как пользоваться:

1. Выберите фигуру в списке.
2. Кнопки "Flood Fill" и "Scanline Fill" запускают заливку. Flood Fill можно запустить кликом по сетке (клик задаёт старт). Зелёный круг показывает стартовую клетку.
3. Ползунок и кнопки "-1", "+1", "Авто" показывают первые N шагов обхода Flood Fill (цвет клетки соответствует порядку обхода, красная клетка это текущий шаг).
4. Переключатель "клик = строка y" или поле y показывают таблицу одной строки Scanline (пересечения X и интервалы заливки). На Canvas строка подсвечена, пересечения отмечены красными точками.
5. Кнопка "Запустить тесты 1-9" выполняет обязательные тесты, кнопка "Сравнить" делает серию замеров для выбранной фигуры.


КАК ЗАДАЁТСЯ МНОГОУГОЛЬНИК

Списком вершин в массиве PRESETS (файл app.js), например:

    { id: 'rect', points: pts([[5, 5], [34, 5], [34, 22], [5, 22]]), seed: { x: 20, y: 13 } }

Стороны строит алгоритм Брезенхема (функция drawPolygonOutline), последняя сторона замыкает контур. У фигуры "Незамкнутый контур" задано closed: false, и последняя сторона не рисуется.

Фигуры: прямоугольник, треугольник, выпуклый пятиугольник, невыпуклая буква U, трапеция, звезда (10 вершин), незамкнутый пятиугольник.


КАК ХРАНИТСЯ ЛОГИЧЕСКИЙ РАСТР

Двумерный массив grid[y][x]:

0 - пусто
1 - граница
2 - заполнено

Состояние хранится в массиве, Canvas его только перерисовывает. Пошаговый режим тоже строится по данным: порядок обхода хранится в order, номер шага каждой клетки в stepIndex.


ИСПОЛЬЗОВАННЫЕ ПРАВИЛА

Связность Flood Fill: 4-связность (соседи (x+1, y), (x-1, y), (x, y+1), (x, y-1)).

Flood Fill: явный стек, без рекурсии. Каждая клетка попадает в стек не более одного раза (массив visited). Заливка идёт только по клеткам со значением 0, границу и края сетки не пересекает. Старт на границе или вне сетки ничего не закрашивает.

Правило вершин в Scanline: ребро учитывается, если min(y1, y2) <= y < max(y1, y2). Верхняя граница диапазона не включается, поэтому общая вершина двух рёбер, идущих в разные стороны от строки, считается один раз. В локальном минимуме или максимуме вершина считается два раза или ни одного. Во всех случаях число пересечений на строке получается чётным.

Горизонтальные рёбра пропускаются при поиске пересечений (в контуре они при этом есть).

Округление: интервал заливки [ceil(x1) .. floor(x2)]. Строка yMax многоугольника не сканируется, её клетки принадлежат контуру.

Клетки границы Scanline не перезаписывает, поэтому сравнение с Flood Fill честное.

СРАВНЕНИЕ FLOOD FILL И SCANLINE

Замер: 7 серий по 300 запусков, взята медиана серии, время на один запуск. Копии сетки создаются до замера, время измеряется через performance.now(). Среда: Node.js 22 (движок V8, как в Chrome). В вашем браузере цифры будут другими, их можно получить кнопкой "Сравнить" в интерфейсе.

Для каждой фигуры: закрашено клеток (одинаково у обоих методов); Flood Fill: клеток из стека / проверок соседей / время; Scanline: строк / проверок "строка x ребро" / время.

Треугольник:             315;  Flood 315 / 1260 / 0.016 мс;  Scanline 22 / 66 / 0.017 мс
Выпуклый пятиугольник:   447;  Flood 447 / 1788 / 0.029 мс;  Scanline 23 / 115 / 0.024 мс
Невыпуклый (U):          469;  Flood 469 / 1876 / 0.022 мс;  Scanline 22 / 176 / 0.019 мс
Трапеция:                425;  Flood 425 / 1700 / 0.020 мс;  Scanline 18 / 72 / 0.014 мс
Звезда:                  166;  Flood 166 / 664 / 0.008 мс;   Scanline 24 / 240 / 0.016 мс

Разница по времени небольшая и зависит от фигуры (на звезде Flood Fill даже быстрее), поэтому делать вывод только по скорости нельзя. Число обработанных элементов отличается принципиально: Flood Fill обрабатывает каждую закрашиваемую клетку, а Scanline обрабатывает строки и рёбра, клетки внутри интервала он просто записывает подряд.

Сводка по принципу работы:

Flood Fill: нужна стартовая точка - да; использует список вершин - нет; что обходится - соседние пиксели.
Scanline:   нужна стартовая точка - нет; использует список вершин - да; что обходится - строки и рёбра.


ВЫВОДЫ

Когда нужен seed. Flood Fill всегда требует стартовую клетку внутри области. Он не знает, что такое "внутри", и заливает всё достижимое. Scanline стартовой точки не требует.

Какой метод использует геометрию многоугольника. Scanline: ему нужен список вершин, чтобы вычислять пересечения строк с рёбрами. Flood Fill работает только с растром и про вершины не знает. Поэтому он применим и к фигурам, заданным просто картинкой (как "заливка" в графическом редакторе).

Что будет при разрыве контура. Flood Fill вытекает наружу и заливает фигуру вместе с окружающим пространством (тест 9). Scanline разрыв не замечает, потому что работает по вершинам, а не по нарисованным пикселям.

Почему результат на границе может зависеть от округления. Пересечение x вещественное, а клетка целая. Интервал ceil(x1)..floor(x2) может включить или исключить клетку у границы, а Брезенхем рисует контур по-своему (округляет к ближайшей клетке). Другое правило округления (например, round вместо ceil и floor) могло бы сдвинуть крайние клетки интервала на одну. В моих тестах при выбранных правилах результаты двух методов совпали полностью (различий 0), потому что Scanline не перезаписывает клетки контура. Другие правила округления я не проверял.
