# Занятие 3. HTTP, Fetch API и работа с JSON

Endpoint: https://jsonplaceholder.typicode.com/users

Метод: GET

Где хранится состояние: в объекте state (users, isLoading, error, filter) в app.js. Весь интерфейс строится из него через render().

Состояния интерфейса:
1. данные не загружены — state.users пуст, ошибки нет
2. загрузка — state.isLoading true, показывается "Загрузка..."
3. успех — пользователи получены, выводятся карточки и статистика
4. ошибка — state.error содержит текст, показывается сообщение об ошибке

Обработка ошибки: loadUsers() оборачивает запрос в try/catch. Если response.ok равен false, выбрасывается Error с кодом ответа. Любая ошибка (сеть, неверный адрес, код ответа) ловится в catch и кладётся в state.error. В finally всегда сбрасывается isLoading, поэтому интерфейс не зависает в "Загрузка..." даже при ошибке.

Фильтрация: по name, username, email, без учёта регистра. getFilteredUsers() возвращает новый массив, исходный state.users не меняется.

Проверка в Network:
При успешном запросе: Request URL — адрес API, Request Method GET, Status Code 200 OK, в Response/Preview виден JSON-массив из 10 пользователей.
При ошибке (временно заменил API_URL на несуществующий адрес): запрос либо вовсе не доходит до сервера, либо возвращается код 404. В обоих случаях response.ok равен false или fetch падает в catch, и на странице вместо вечной "Загрузка..." появляется сообщение об ошибке.
