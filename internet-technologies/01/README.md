# Занятие 1. Как работает веб-приложение

## Ответы

**Где в программе хранится состояние?**
Состояние хранится в одной переменной `value` в `app.js`.

**Какая функция обновляет интерфейс?**
Функция `render()`: она записывает текущее значение `value` в элемент `#value`
и обновляет текст в `#status` в зависимости от знака числа.

**Какие события обрабатываются?**
Событие `click` на трёх кнопках: `#increase`, `#decrease`, `#reset`.

**Что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса?**
Значение `value` изменится в памяти, но интерфейс останется прежним — на экране
будет показано старое число, пока `render()` не будет вызвана снова.
